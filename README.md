# 心動視線 · Heart Rush

手機與電腦皆可玩的原創園遊會小遊戲，使用 HTML、CSS、JavaScript 與 Canvas，無外部素材、套件或建置步驟。

遊戲網址：https://tzfei923-star.github.io/Game-test/

## 玩法

- 按下「開始心動」，每局 60 秒。
- 按住畫面下方箭頭移動；電腦也可用方向鍵或 A / D。
- 按住人物累積好感，必須在有效距離內；手機可一手移動、一手鎖定。
- 好感滿格獲得 100 分；紫色進度是對手的邀請進度。
- 魅力耗盡需恢復至 30% 才能再發射，放開目標即可恢復。
- 暫停按鈕或切換分頁會暫停遊戲；最佳分數保存在目前瀏覽器。

## 修改與發布

所有程式與繪圖位於 `index.html`，可直接用瀏覽器開啟。修改後提交至 main，GitHub Pages 從 main 的根目錄發布。無需安裝 App、購買網域或設定後端。

這是第一版原型，人物與場景以程式繪製，不含第三方遊戲素材。
